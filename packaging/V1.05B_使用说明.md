# ZZZ Drive Optimizer V1.05B（离线扫描器版）

双击 `ZZZ_Drive_Optimizer_V1.05B.exe` 启动。请保持 `scanner` 文件夹与 EXE 位于同一目录。

扫描流程：

1. 在“1. 录入驱动盘”顶部点击绿色“打开驱动盘扫描器”。
2. 在扫描器窗口依次点击“检测窗口”和“开始扫描”。
3. 扫描完成后打开产物文件夹。
4. 回到配装器，点击“导入 JSON（自动识别）”。
5. 选择 `export.json` 或 `export.partial.json`，确认合并摘要。

扫描器支持 Windows x64 和简体中文游戏界面。扫描期间不要移动鼠标、滚动库存或改变排序；HDR、过饱和、UI 缩放和窗口遮挡可能影响 OCR。

本版附带 ZZZ-Scanner.Next 1.0.45 自包含离线包、.NET 8 和 PP-OCRv5 ONNX 模型。第三方授权与校验信息位于 `scanner` 文件夹。

V1.05 强化了录入提示、截图粘贴区、章节标题和面板数值层级；代理人及音擎具体数字使用更醒目的金黄色大号粗体。蕾米埃尔·丹已补充同系列 200×200 Q 版头像。

本软件用于库存管理和基础面板配装，不是完整伤害计算器。历次错误、修正口径和回归信息保存在源码仓库的 `CORRECTION_LOG.md` 与 `RELEASE_NOTES_*.md`。
