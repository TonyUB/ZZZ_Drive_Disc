# ZZZ Drive Optimizer V1.04A（精简版）

双击 `ZZZ_Drive_Optimizer_V1.04A.exe` 启动。程序会在本机开启临时网页服务并自动打开浏览器；关闭命令窗口即可退出。

本版不带扫描器，也不显示扫描器启动按钮，适合手工录入、图片 OCR、导入现有扫描结果或计算器通用 JSON。

V1.04 将代理人、驱动盘套装和相关选择列表统一为版本倒序；初次进入与清空配装条件时默认显示最新版本代理人，不再固定回到叶瞬光。代理人面板和专武数据已改为更大、以白色为主的高对比度显示。

库存数据默认保存在当前 Windows 用户配置目录的 `ZZZDriveBuilder/state.json`。A/B 版本可以直接读取同一库存，无需转换。

本软件用于库存管理和基础面板配装，不是完整伤害计算器。历次错误、修正口径和回归信息保存在源码仓库的 `CORRECTION_LOG.md` 与 `RELEASE_NOTES_*.md`。
