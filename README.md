# ZZZ Drive Optimizer v1.14

绝区零驱动盘配装器。v1.14 以 v1.13 为兼容基线，重点修正 3.0 代理人佩洛伊斯在“未升级技能 / 未计入核心技F成长”状态下的面板口径，并修正拂晓行纪 4 件套暴击伤害被写入角色详情面板的问题。

## v1.14 更新

### 佩洛伊斯面板状态适配

- 功能 3.1「代理人选择」新增“核心技 / 面板状态”下拉。
- 佩洛伊斯默认使用“未升级技能 / 实机截图校准”口径，用于贴近用户提供的 3.0 实机代理人信息截图。
- 该默认口径下：佩洛伊斯基础攻击按 911 参与最终攻击计算，异常精通基准按 120 参与计算，不额外计入核心技F的暴击率 +14.4%。
- 需要按资料站满核心F口径测试时，可手动切换到“核心技 F / MAX”。满核心资料口径保留为：生命 7673、攻击 924、防御 612、冲击力 94、暴击率 19.4%、暴击伤害 50%、异常精通 93、异常掌控 94。

### 拂晓行纪 4 件套面板口径修正

- 拂晓行纪 2 件套以太伤害 +10% 继续计入稳定属性。
- 拂晓行纪 4 件套的以太代理人暴击伤害 +30% 不再写入“面板暴伤”。
- 拂晓行纪 4 件套的触发攻击力 +10% 继续只作为实战攻击 / 排序参考。
- 结果摘要已更新为：角色60级成长、所选核心技/面板状态、音擎基础与高级属性、驱动盘主副属性和2件套静态效果计入角色详情面板；4件套和音擎技能类效果统一作为实战参考。

### 与 v1.13 的兼容

- 保留 v1.13 的库存筛选优化：功能 2 的“套装”筛选下拉只显示当前库存中实际存在的套装。
- 功能 1 的录入套装下拉、功能 3 的 4 件套 / 2 件套下拉仍保留完整套装池，便于录入与规划。
- 状态版本升级为 `114`，继续兼容旧库存 JSON、已存套装与驱动盘归属关系。

## 使用方式

Windows 下双击 `ZZZ_Drive_Optimizer_v1.14.exe`。程序会启动本地服务并自动打开浏览器；黑色命令窗口关闭即退出程序。

## 安全边界

本工具不读取游戏进程、不读取内存、不抓包、不要求账号密码、不读取 Cookie / Token，也不修改游戏文件；只处理用户主动录入、导入、上传或粘贴的截图与 JSON 数据。

## 构建

```bash
go test ./...
go vet ./...
GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-s -w" -o ZZZ_Drive_Optimizer_v1.14.exe .
```
