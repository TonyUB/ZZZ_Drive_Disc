# ZZZ Drive Optimizer V1.01A（精简版）

双击 `ZZZ_Drive_Optimizer_V1.01A.exe` 启动。程序会在本机开启临时网页服务并自动打开浏览器；关闭命令窗口即可退出。

本版不带扫描器，也不显示扫描器启动按钮，适合手工录入、图片 OCR、导入现有扫描结果或计算器通用 JSON。

库存数据默认保存在当前 Windows 用户配置目录的 `ZZZDriveBuilder/state.json`。如曾使用 V1.01B 或 V1.0A/B，可直接读取同一库存，无需转换。

V1.01 已修正异常代理人结果面板：顶部仅显示游戏角色详情口径的面板异常精通和最终面板攻击；音擎技能、4件套触发及队伍/战斗条件增益不会混入该面板。

本软件用于库存管理和基础面板配装，不是完整伤害计算器。右上代理人头像只表示本地保存方案的占用，不代表游戏内真实装备关系。
